# منصة التفوق | Manassat Al-Tafawoq

منصة عربية محلية لتنظيم مراجعة البكالوريا الجزائرية، بواجهة RTL وثيم يتكيف مع اختيار المستخدم.

## الخصائص
- يبدأ التسجيل باختيار الشعبة أولاً، ثم الاسم والصيغة اللغوية واللغة الثالثة لشعبة اللغات.
- لوحة متابعة ونسبة إنجاز ونشاط أسبوعي وأولويات.
- موادي: مواضيع البكالوريا بحالات (لم أبدأ / قيد الحل / تم الحل)، بحث عن الموضوع، روابط DzExams للبكالوريا والفروض والدروس، وإدارة الدروس الشخصية بحالة تقدم وحذف.
- بنك مستعاد من الملف الأصلي يضم 482 بطاقة: الإنجليزية والفرنسية والإسبانية، شخصيات وتواريخ التاريخ، ومصطلحات الجغرافيا؛ مع اختبار سريع ونطق باللغة الصحيحة ومراجعة متباعدة SM-2 مبسطة.
- مؤقت تركيز، حاسبة معدل بمعاملات قابلة للتعديل، ونسخ احتياطي JSON.
- بحث شامل عبر `Ctrl/Cmd + K`، اختصارات أرقام، وضع ليلي وفاتح.
- 100 رسالة تحفيزية أصلية، وتقسيم كسول للصفحات والبيانات الثقيلة ومكتبات الرسوم والحركة.
- تخزين محلي دون حسابات أو خادم أو تحليلات.


## النشر على GitHub Pages
1. أنشئ مستودع GitHub وارفع الملفات إلى فرع `main`.
2. من Settings → Pages اختر **GitHub Actions** كمصدر النشر.
3. سيعمل سير العمل `.github/workflows/deploy.yml` تلقائياً عند كل دفع إلى `main`، ويستخدم `npm install` لأن المستودع لا يتضمن ملف قفل حالياً.
4. عنوان الموقع سيكون `https://USERNAME.github.io/REPOSITORY/`.

## هيكلة المشروع
```text
src/
  components/   # عناصر الواجهة والتسجيل والإطار العام
  data/         # الشعب والمواد والمعاملات والمصطلحات والموارد والرسائل
  hooks/        # إدارة الحالة
  lib/          # التخزين، التقدم، الحساب، التكرار المتباعد
  pages/        # الرئيسية والمواد والمصطلحات والتركيز والحاسبة والإعدادات
  styles/       # Design Tokens والأنماط
  test/         # اختبارات Vitest
public/         # manifest وService Worker والأيقونات
e2e/            # اختبارات Playwright
```

## Design Tokens
- المسافات: مضاعفات 4px من `--space-1` إلى `--space-10`.
- الزوايا: 9 / 14 / 20 / 28px.
- اللون المحايد والخلفيات في `src/styles/tokens.css`.
- اللون الأساسي أحادي: أزرق للذكور ووردي للإناث، مع درجات مشتقة.
- الخط الافتراضي عربي آمن؛ أضف ملفات WOFF2 مرخصة ذاتياً إلى `public/fonts` ثم عرّف `@font-face` محلياً.

## بيانات المعاملات
`src/data/coefficients.ts` يحتوي معاملات أولية قابلة للتعديل. القيم غير المدققة موسومة بـ TODO، ولا ينبغي اعتبارها مرجعاً رسمياً.

## الخصوصية والبيانات
تبقى البيانات في `localStorage` تحت المفتاح `bacStandard_v3`، مع ترحيل بيانات `bacStandard_v1` القديمة. لا ترسل المنصة البيانات إلى أي خادم؛ استخدم النسخ الاحتياطي JSON لنقل التقدم بين الأجهزة.

## خارطة الطريق
- تدقيق بيانات المواد والمواضيع وفق مصادر رسمية لكل دورة.
- تدقيق المحتوى المستعاد وربطه بمراجع المنهاج الرسمية.
- تحسين تغطية اختبارات Playwright، وفحص Lighthouse على بيئة النشر.
- إضافة heatmap شهري وشارات إنجاز موسعة، وإيماءات لمس قابلة للتخصيص.

## English
An Arabic RTL, local-first study planner for Algeria's Baccalaureate exams. It includes onboarding, subject tracking, spaced-repetition flashcards, focus timer, grade calculator, local JSON backup, PWA shell, and GitHub Pages deployment.

## التخزين المحلي واستعادة البيانات

- تحفظ النسخة الحالية تقدم الطالب في `localStorage` تحت المفتاح `bacStandard_v3`، مع ترحيل تلقائي للبيانات الموجودة في `bacStandard_v1` عند فتحها لأول مرة.
- عند فشل القراءة أو الحفظ، تعرض الواجهة تحذيراً واضحاً بدلاً من تجاهل الخطأ بصمت. عند امتلاء مساحة المتصفح يبقى التقدم متاحاً في الجلسة الحالية لكنه لا يكون محفوظاً بعد إغلاقها؛ صدّر نسخة JSON فور ظهور التحذير.
- يدعم قسم الإعدادات تصدير نسخة JSON واستيراد النسخ الحالية والقديمة، بما فيها نسخ التطبيق الأصلي ذي البنية `subjects` الكائنية و`profile.lang`. هذه آلية نقل يدوية وليست مزامنة سحابية.
- لا توجد خدمة سحابية أو حسابات مستخدمين حالياً. إضافة المزامنة لاحقاً تتطلب خادماً موثوقاً، ومصادقة، وقواعد صلاحيات، وتشفيراً أثناء النقل، وسياسة واضحة للتعارض بين تعديلات الأجهزة. لا تُرسل بيانات الطالب إلى أي جهة في النسخة الحالية.

## تحميل الموارد والأداء

صفحتا المصطلحات والمواد محملتان كسولاً عبر `React.lazy`، كما أن `terms.json` و`resources.json` يُحمّلان ديناميكياً عند فتح الصفحة المعنية فقط. البحث يبني فهرساً نصياً مُطبّعاً مرة واحدة لكل مجموعة بيانات، ولا يرسم كل البطاقات دفعة واحدة.

## الشعبة والاتجاه

تطلب شاشة البداية اختيار الشعبة قبل بقية بيانات الملف الشخصي. عند تغيير الشعبة من الإعدادات تُحدّث قائمة المواد والمعاملات، مع الاحتفاظ بتقدم المواد المشتركة وأرشفة المواد الأخرى محلياً عند تغيير الشعبة. المنصة عربية RTL، بينما تُعزل الأرقام والمقاطع اللاتينية باتجاه LTR عند الحاجة.
